# Truth-source selection standard

Select exactly one truth source for every factor during Stage 1. Selection must use paper evidence quality and intended IC-analysis scope, never reproduced metric closeness or local data convenience.

Prefer, in order:

1. a row explicitly reporting the target factor under a fully specified IC protocol;
2. the paper's principal/default IC result block over robustness alternatives;
3. a block with a narrow source locator and directly printed numeric metrics;
4. a protocol whose method is unambiguous and homogeneous across its row block.

Do not select a source that lacks the factor row. If equally authoritative alternatives remain, record an extraction gap and require review rather than deferring selection to Stage 3 or Stage 6. Local support may make the selected source non-executable, but it does not authorize truth reselection.
